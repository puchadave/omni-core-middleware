# Continue + OmniRoute

1. Copy `config.yaml` to `~/.continue/config.yaml` (or merge models into existing config).
2. Export `OMNIROUTE_API_KEY`.
3. Restart Continue and select an OmniRoute model (`auto/smart`, `auto/coding`, `omni-ecom-coding-smart`).

Base URL: `http://192.168.176.22:20128/v1` (OpenAI-compatible).
