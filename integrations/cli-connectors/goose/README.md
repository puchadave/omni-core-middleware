# Goose + OmniRoute

1. Merge `profiles.yaml` values into your Goose profile/config.
2. Export `OMNIROUTE_API_KEY`.
3. Ensure `openai_host` points to `http://192.168.176.22:20128/v1` and select OmniRoute models (`auto/smart`, `auto/fast`).

Use `../scripts/nexus-cli.sh` for NEXUS/Proxmox automation tasks from shell/tool steps.
