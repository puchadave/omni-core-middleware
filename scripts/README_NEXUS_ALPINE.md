# NEXUS Native Alpine LXC Automation

All scripts use **Alpine Linux 3.x amd64**, Proxmox storage **`local`**, unprivileged LXC, **OpenRC** (no systemd/Docker), and first-boot re-keying for template clones.

## Scripts

| Script | Purpose |
|---|---|
| `lib_nexus_proxmox.sh` | Shared Proxmox/Alpine helpers: template filter `alpine-3.*amd64`, `pct create` with `local` rootfs, IP parsing, remote SSH execution, tar-based sync into LXC. |
| `build_native_omniroute_lxc.sh` | Builds `omniroute-gateway` LXC (2 cores / 2048 MB / 8 GB), installs `omniroute@latest`, writes 6 `omni-*` combos, failover/cache tuning, OpenRC service + first-boot re-key hook. |
| `build_native_omnicore_lxc.sh` | Builds `omnicore-middleware` LXC (4 cores / 4096 MB / 16 GB), syncs middleware source, creates venv, installs requirements, initializes SQLite + NEXUS event store, OpenRC service + first-boot secret rotation/DB init. |
| `build_native_shopware_lxc.sh` | Builds standalone `shopware-server` LXC (4 cores / 4096 MB / 20 GB), installs MariaDB/PHP-FPM/Nginx/Shopware 6 via OpenRC, applies performance tuning, preconfigures OMNI-CORE integration/webhooks when `--middleware-ip` set, first-boot secret rotation. |
| `tune_and_verify_pair.sh` | Syncs combos/timeouts/caching between gateway and middleware, verifies `/v1/models`, 6 combos, `/health`, `/api/ai-control/test-connection`, and PII guard routing to `omni-local-gdpr`. Aborts on any failure. |
| `export_golden_alpine_templates.sh` | Deep-sanitizes LXCs (OmniRoute, OMNI-CORE, optional Shopware), disables runtime keys, enables first-boot hooks, exports `vzdump` zstd templates to `/var/lib/vz/template/cache/`, optionally syncs to Node 2. |
| `master_build_and_template.sh` | One-click pipeline: OmniRoute -> OMNI-CORE -> optional old-container backup -> optional Shopware -> tune/verify -> export templates, with JSON summary. |
| `backup_old_containers.sh` | `vzdump` backup of existing/old LXC containers before replacement. |
| `tune_proxmox_nodes.sh` | Idempotent Proxmox VE host performance/system tuning (sysctl, ksmtuned, fstrim, scheduler hints). |

## One-Click Master Run (on Proxmox Node 1)

```bash
cd /path/to/omni-core-middleware
bash scripts/master_build_and_template.sh \
  --omniroute-node LOCAL \
  --omnicore-node LOCAL \
  --node2-host root@192.168.178.251 \
  --omniroute-ip 192.168.176.21/24,gw=192.168.176.1 \
  --omnicore-ip 192.168.176.22/24,gw=192.168.176.1 \
  --shopware-api-url https://shop.example.com/api \
  --shopware-client-id SWIA-XXXX \
  --shopware-client-secret XXXX
```

For split nodes:

```bash
bash scripts/master_build_and_template.sh \
  --omniroute-node LOCAL \
  --omnicore-node root@192.168.178.251 \
  --node2-host root@192.168.178.251
```

With Shopware: add `--with-shopware` (and optional `--shopware-node`, `--backup-old-ctids "ID,ID"`). 

## Clone Commands Generated by Master

```bash
pct create 301 local:vztmpl/alpine-3-omniroute-gateway-amd64.tar.zst \
  --hostname omniroute-gateway --cores 2 --memory 2048 \
  --storage local --rootfs local:8 --net0 name=eth0,bridge=vmbr0,ip=dhcp \
  --ostype alpine --unprivileged 1 --features nesting=1,keyctl=1 --onboot 1

pct create 302 local:vztmpl/alpine-3-omnicore-middleware-amd64.tar.zst \
  --hostname omnicore-middleware --cores 4 --memory 4096 \
  --storage local --rootfs local:16 --net0 name=eth0,bridge=vmbr0,ip=dhcp \
  --ostype alpine --unprivileged 1 --features nesting=1,keyctl=1 --onboot 1

pct create 303 local:vztmpl/alpine-3-shopware-server-amd64.tar.zst \
  --hostname shopware-server --cores 4 --memory 4096 \
  --storage local --rootfs local:20 --net0 name=eth0,bridge=vmbr0,ip=dhcp \
  --ostype alpine --unprivileged 1 --features nesting=1,keyctl=1 --onboot 1
```

## Verification

```bash
bash -n scripts/*.sh
# optional:
shellcheck -x scripts/*.sh
```

No `local-lvm` or `arm64` is used; templates are filtered strictly for `alpine-3.*amd64` and rootfs/storage are `local`.
